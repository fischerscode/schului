schului
-------

schului.exe startet den Editor für Lehrkräfte.

Für Lernende:
In der Lehreransicht über das Archivsymbol „Schülerpaket exportieren“ einen
Zielordner wählen. Der neue Paketordner enthält die Einheit, die passende BAT
und alle benötigten schului-Programmdateien. Den gesamten Ordner verteilen und
start-lernen.bat als Schüler-Startpfad hinterlegen. Die Zielsoftware selbst
muss auf den Schülerrechnern verfügbar sein.

Beim manuellen Zusammenstellen:
Die fertige Einheit als unterricht.schului neben schului.exe speichern.
In der Schülerverwaltung start-lernen.bat als Startpfad hinterlegen.
Diese öffnet direkt den Unterricht ohne Lehreransicht. Fehlt die Datei oder ist
sie ungültig, erscheint eine Fehlermeldung; der Editor wird nicht geöffnet.

Alternativ mit einer beliebigen Lerndatei starten:
schului.exe --lesson-file "C:\Unterricht\Text bearbeiten.schului"
oder: start-lernen.bat "C:\Unterricht\Text bearbeiten.schului"

Für Lehrkräfte:

1. Über das Zahnrad „Zielsoftware“ wählen: geöffnetes Fenster oder Programmdatei.
2. Eigene Lernschritte, Texte und Tipps anlegen.
3. Einen Text als „Interaktiver Begriff“ bearbeiten.
4. „Ziel in Anwendung auswählen“ drücken, im geöffneten Zielprogramm auf ein
   Element zeigen und F8 drücken. Esc bricht ab; der Pfad wird automatisch eingefügt.
5. Speichern und mit dem Dreieck als Lernsitzung ausprobieren.

Bei mehreren passenden Programmfenstern bietet die Lernsitzung eine Fensterauswahl.
Andere Rechner können andere Programmpfade haben; diese im Editor anpassen.
Die Zielsoftware muss installiert bzw. bereits geöffnet sein. Manche Anwendungen
stellen keine geeigneten Accessibility-Elemente für einzelne Hover-Ziele bereit.

start-inspector.cmd mit einer .schului-Datei als Argument öffnet den Inspector
für diese Unterrichtseinheit. Online-Übungen benötigen Internet und Microsoft
Edge WebView2.

Den ganzen Programmordner zusammenlassen; die EXE allein genügt nicht.
Unterstützt werden Lerndateien der Version 2 mit allgemeinen Programmeinstellungen
und exakten Zielpfaden. Ältere Dateien müssen neu angelegt werden.
Vor dem Unterricht auf einem Lernenden-PC testen.
