schului
-------

schului.exe startet den Editor für Lehrkräfte.

1. Über das Zahnrad „Zielsoftware“ wählen: geöffnetes Fenster oder Programmdatei.
2. Eigene Lernschritte, Texte und Tipps anlegen.
3. Einen Text als „Interaktiver Begriff“ bearbeiten.
4. „Ziel in Anwendung auswählen“ drücken, im geöffneten Zielprogramm auf ein
   Element zeigen und F8 drücken. Esc bricht ab; der Pfad wird automatisch eingefügt.
5. Speichern und mit dem Dreieck als Lernsitzung ausprobieren.

Bei mehreren passenden Programmfenstern bietet die Lernsitzung eine Fensterauswahl.
Andere Rechner können andere Programmpfade haben; diese im Editor anpassen.
Die Zielsoftware muss installiert bzw. bereits geöffnet sein. Manche Anwendungen
stellen keine geeigneten Accessibility-Elemente für einzelne Hover-Ziele bereit.

Draw ist nur ein optionales Beispiel. start-beispiel.cmd und start-inspector.cmd
verwenden dieses Beispiel und benötigen LibreOffice. Andere Einheiten benötigen
kein LibreOffice. Online-Übungen benötigen Internet und Microsoft Edge WebView2.

Den ganzen Programmordner zusammenlassen; die EXE allein genügt nicht.
Neue Lerndateien verwenden Formatversion 2; alte Draw-Dateien bleiben lesbar.
Vor dem Unterricht auf einem Lernenden-PC testen.
